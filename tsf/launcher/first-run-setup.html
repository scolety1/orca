One-time setup

Thousand Sunny Fleet runs as a plugin inside Orca. This machine hasn't registered it yet, so before the app can open, Orca needs to be told where to find it — a one-time step done once per machine, in Orca's own Settings.

1

In Orca, open Settings → Plugins and turn on Plugin system.

2

Expand Development and paste this exact folder path, then click Add path:

resolving…
3

Enable Thousand Sunny Fleet Foundation once it appears in the plugin list.

That's it — every future launch is a plain double-click.
